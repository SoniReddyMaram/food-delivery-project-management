# Project Lifecycle

## 1. Overview

The Food Delivery Mobile Application will follow five broad project lifecycle stages:

1. Initiation
2. Planning
3. Execution
4. Monitoring & Control
5. Closure

---

## 2. Initiation

The project begins with a business need to provide customers with a convenient digital food-ordering platform.

Key activities:

- Identify business problem
- Define project objectives
- Identify key stakeholders
- Define high-level scope
- Identify major risks
- Develop project charter
- Obtain project authorization

### Main Output

Project Charter

---

## 3. Planning

The project team develops a detailed plan for delivering the application.

Key activities:

- Define scope
- Gather requirements
- Create Work Breakdown Structure
- Develop schedule
- Estimate resources
- Develop budget
- Identify and assess risks
- Create communication plan
- Define stakeholder management approach

### Main Outputs

- Project Management Plan
- Scope Statement
- Requirements
- WBS
- Schedule
- Budget
- Risk Register
- Communication Plan

---

## 4. Execution

The project team performs the planned work.

Key activities:

- UI/UX design
- Application development
- Backend development
- Database development
- Payment integration
- Delivery tracking development
- Testing
- Deployment preparation

The Project Manager coordinates the team and manages stakeholders during execution.

---

## 5. Monitoring and Control

Monitoring and controlling occurs throughout project execution.

The Project Manager monitors:

- Schedule
- Cost
- Scope
- Quality
- Risks
- Issues
- Resources
- Stakeholder expectations

Corrective action is taken when the project deviates from the approved plan.

---

## 6. Closure

The project is closed after the agreed deliverables have been completed and accepted.

Closure activities include:

- Obtain final approval
- Confirm deliverables
- Complete documentation
- Close contracts
- Release project resources
- Record lessons learned
- Conduct final project review
- Transition the product to operations

---

## 7. Project Lifecycle Flow

```text
Initiation
    ↓
Planning
    ↓
Execution
    ↕
Monitoring & Control
    ↓
Closure
    ↓
Operations


```


# 8. Food Delivery App Example

| Lifecycle Stage | Example Activity |
|---|---|
| Initiation | Identify need for food delivery platform |
| Planning | Define requirements and schedule |
| Execution | Develop the application |
| Monitoring & Control | Track schedule, cost, scope, quality and risks |
| Closure | Obtain approval and transition application to operations |

The project lifecycle provides a structured approach for moving a project from an initial business need through planning, execution, monitoring, and final closure.

# 🧠 Lesson 3 — What You Need to Remember

Don't try to memorize everything.

Remember this:

### **1. Initiation**
> Should we do it?

### **2. Planning**
> How will we do it?

### **3. Execution**
> Let's do it.

### **4. Monitoring & Control**
> Are we doing it correctly and staying on track?

### **5. Closure**
> Is it finished and formally accepted?

The easiest memory trick:

> **START → PLAN → DO → CHECK → CLOSE**

# 📝 Practice

Let's test you.

A company wants to build an **online banking application**.

Tell me which lifecycle stage applies to each activity:

1. Management decides the project is needed.
2. The team creates the project budget.
3. Developers start coding.
4. The PM discovers the project is two weeks behind schedule.
5. The customer approves the final application.
6. The team documents lessons learned.

### Answers

1. **Initiation** — deciding whether/why the project should happen.
2. **Planning** — budget is part of project planning.
3. **Execution** — the team is performing the work.
4. **Monitoring & Control** — we're tracking schedule and taking corrective action.
5. **Closure** — final acceptance.
6. **Closure** — lessons learned are documented when closing the project.
