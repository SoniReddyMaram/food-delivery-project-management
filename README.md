# Food Delivery App — Project Management Case Study

## 📌 Project Overview

This repository documents the project management process for a fictional Food Delivery Mobile Application.

The application allows customers to:

* Browse restaurants and food items
* Add items to a shopping cart
* Place orders
* Make online payments
* Track deliveries

This project is being used as a practical project management case study to demonstrate planning, execution, monitoring, risk management, Agile practices, stakeholder management, and project closure.

---

## 🎯 Business Objective

The business wants to increase online food orders and revenue by providing customers with a convenient digital food-ordering platform.

---

## 🎯 Project Objective

Design, develop, test, and launch a food delivery application within the approved scope, schedule, budget, and quality requirements.

---

## 📦 Major Deliverables

* Customer mobile application
* Restaurant management system
* Backend/API
* Database
* Online payment integration
* Delivery tracking
* Admin dashboard
* Testing documentation
* Production deployment

---

## 👥 Key Stakeholders

| Stakeholder         | Role                                        |
| ------------------- | ------------------------------------------- |
| Project Sponsor     | Provides funding and executive support      |
| Project Manager     | Plans and coordinates the project           |
| Product Manager     | Defines product requirements and priorities |
| Development Team    | Builds the application                      |
| QA Team             | Tests the application                       |
| Restaurant Partners | Provide restaurants and menus               |
| Delivery Partners   | Deliver customer orders                     |
| Customers           | Use the application                         |
| Payment Provider    | Processes online payments                   |

---

## ⚠️ Initial Project Risks

| Risk                        | Potential Impact                           |
| --------------------------- | ------------------------------------------ |
| Development delays          | Launch may be delayed                      |
| Changing requirements       | Scope may increase                         |
| Payment integration failure | Customers may be unable to complete orders |
| Security vulnerabilities    | Customer data may be exposed               |
| Budget overrun              | Project may exceed approved funding        |
| Poor application quality    | Customers may have a poor experience       |
