# Deliverables, Milestones, Tasks and Outcomes

## 1. Overview

Projects contain different types of work and results.

The key concepts covered in this project are:

- Deliverables
- Milestones
- Tasks
- Activities
- Outcomes
- Business Benefits

---

## 2. Deliverable

A deliverable is a specific and verifiable output produced by the project.

Examples for the Food Delivery Application:

- Customer Application
- Restaurant Portal
- Admin Portal
- Payment Integration
- Testing Package
- Production Deployment

---

## 3. Project Deliverables

| ID | Deliverable | Description |
|---|---|---|
| D1 | Project Documentation | Project management documents |
| D2 | UI/UX Design | User interface and experience designs |
| D3 | Customer Application | Mobile application for customers |
| D4 | Restaurant Portal | Restaurant management interface |
| D5 | Payment Integration | Online payment functionality |
| D6 | Admin Portal | Administrative management system |
| D7 | Testing Package | Test documentation and results |
| D8 | Production Deployment | Production-ready application |

---

## 4. Milestones

A milestone is a significant point or event in a project that indicates important progress or achievement.

Examples:

| Milestone | Target |
|---|---|
| Project Charter Approved | Week 1 |
| Requirements Approved | Week 3 |
| UI/UX Design Approved | Week 6 |
| Development Complete | Week 14 |
| Testing Complete | Week 18 |
| User Acceptance Testing Complete | Week 20 |
| Production Launch | Week 21 |
| Project Closure | Week 22 |

---

## 5. Tasks

A task is a specific piece of work that must be performed.

Examples:

- Create login screen
- Develop restaurant search
- Develop shopping cart
- Configure payment API
- Execute test cases
- Prepare deployment environment

---

## 6. Activities

Activities are work performed as part of the project.

Examples:

- Requirements gathering
- UI/UX design
- Software development
- Testing
- Deployment

---

## 7. Outcomes

An outcome is the result or change achieved through the project deliverables.

Example:

**Deliverable:**
Food Delivery Application

**Outcome:**
Customers can conveniently order food online.

---

## 8. Business Benefits

Business benefits are the value the organization receives from the project.

Examples:

- Increased online orders
- Improved customer convenience
- Reduced manual order processing
- Better order tracking
- Improved customer experience

---

## 9. Deliverable Acceptance

Deliverables should be evaluated against agreed acceptance criteria.

Example:

### Customer Application

Acceptance criteria:

- Customers can register and log in.
- Customers can search restaurants.
- Customers can browse menus.
- Customers can add items to the cart.
- Customers can place orders.
- Customers can complete payment.
- Customers can track orders.
- No critical defects remain.

---

## 10. Deliverable vs Milestone vs Task vs Outcome

| Concept | Meaning | Example |
|---|---|---|
| Deliverable | Output produced | Customer Application |
| Milestone | Important project checkpoint | Requirements Approved |
| Task | Specific piece of work | Develop Login Screen |
| Activity | Project work | Software Development |
| Outcome | Result achieved | Customers can order food online |
| Business Benefit | Value to organization | Increased online orders |
